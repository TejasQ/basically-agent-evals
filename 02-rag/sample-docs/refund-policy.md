# Refund and Return Policy

## Return Window

Returns are accepted within **14 days** of purchase. After this period, returns cannot be processed.

## Eligibility

To be eligible for a return:
- The item must be in its original condition
- All original packaging must be included
- Proof of purchase (receipt or order number) is required

## Process

1. Contact customer support within the 14-day window
2. Receive a return authorization number
3. Ship the item back using the provided prepaid label
4. Refund will be processed within 3-5 business days after we receive the item

## Exceptions

The following items cannot be returned:
- Digital products and downloads
- Personalized or custom-made items
- Items marked as "final sale"

## Contact

For questions about returns, contact support@example.com or call 1-800-SUPPORT.
